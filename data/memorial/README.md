# Memorial exposure bracket

This directory contains 15 RGB PNG images supplied for exposure-fusion
experiments. They are 484 x 714 pixels, with 8 bits per channel. The original
filenames are preserved: `memorial00.png` through `memorial15.png`, except
`memorial05.png`, which was not supplied.

The filenames correspond to the [OpenCV HDR exposure test set](https://github.com/opencv/opencv_extra/tree/4.x/testdata/cv/hdr/exposures).
That set's [readme](https://raw.githubusercontent.com/opencv/opencv_extra/4.x/testdata/cv/hdr/exposures/readme.txt)
credits the images to Paul Debevec. Confirm the provenance and usage terms of
these supplied files before redistributing them or publishing results.

The files were moved without image preprocessing. Their matching dimensions
were checked; alignment has not been independently verified.
